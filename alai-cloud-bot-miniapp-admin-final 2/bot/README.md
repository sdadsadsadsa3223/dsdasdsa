# Alai Cloud · Telegram Mini App

Сайт и бот работают одним Node.js-процессом без внешних npm-зависимостей.

## Запуск

1. В Render добавьте Environment Variables из `.env.example`.
2. Обязательно задайте `TELEGRAM_BOT_TOKEN` и `MINI_APP_URL`.
3. `MINI_APP_URL` — это публичный HTTPS-домен Render, не GitHub-ссылка и не localhost.
4. `MANAGER_CONTACT_URL` оставьте `https://t.me/alairustam`.
5. Запуск выполняется командой `npm start`; Render сам передаст приложению `PORT`.

Токен бота хранится только в Render Environment Variables. В текущем режиме заказ открывает чат менеджера `@alairustam` с готовым текстом; пользователь нажимает «Отправить». `MANAGER_CHAT_ID` понадобится, если включите доставку заказов через самого бота.

## Админка

1. Напишите боту `/id` и скопируйте числовой `chat_id`.
2. Добавьте его в Render как `ADMIN_CHAT_ID`.
3. Перезапустите сервис и отправьте боту `/admin`.

В админке есть статистика, список пользователей с никнеймами и chat_id, последние заказы, CSV-выгрузка и рассылка. Для рассылки нажмите «Новая рассылка», затем отправьте боту текст, фото, видео или стикер. Сообщение уйдёт только пользователям, которые уже запускали бота; заблокированные чаты будут отмечены автоматически.

Данные сохраняются в `DATA_DIR/state.json`. На Render лучше подключить Persistent Disk и поставить `DATA_DIR=/var/data`, иначе список пользователей сбросится при пересоздании сервиса.

Стикер необязателен: отправьте боту `/stickerid`, затем сам стикер. Бот вернёт `file_id`; его можно сохранить в `WELCOME_STICKER_ID`.
